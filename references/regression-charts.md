# 迴歸與散點圖

## 樣本與估計

- 先依索引對齊 x、y，再取共同有效樣本；圖上點、擬合線與統計註記使用同一估計樣本。預測點或尚未實現的 outcome 不計入 N。
- 確認轉換與 lag 在估計前已完成，且沒有把預測資料混入歷史擬合樣本。
- OLS 線描述條件關係，不代表因果。時間序列若有趨勢、自相關或異質變異，普通 t-stat 可能不適合作推論。
- 二次項只在關係假設或診斷支持時使用，不因曲線看起來更貼合就自動加入。

## 繪製方式

散點使用適度透明度。擬合線必須用排序後的 x 或規則網格繪製，不能直接依原始資料順序連線。

註記密度依媒介：研究版可保留方程式、r、R²、N 等；客戶／小尺寸版只呈現有助判斷的統計，其餘保留在研究紀錄。統計須可追溯到實際有效樣本，不因隱藏文字而改估計；若顯示 t-stat，交代估計方法，不把普通 OLS t 值冒充穩健推論。分組及多 horizon 比較仍需顯示各組／各期有效 N，可置於精簡圖例或面板標題。

尺度差異大或離群值明顯時，先提供未裁切版本，再由使用者決定是否限制範圍。不要默默移除離群值。

## 最新觀察與未知結果

- 呼叫端明確提供要標記的日期、x、y（可未知）及實際／預測身分；不可把最後一筆完整的舊 x、y 當成目前最新狀態。
- 最新 x、y 均已知時，以外框、不同 marker 或註解突出日期及位置。
- y 若為未來三個月變化，最新 x 可能尚無對應 y。只畫 x 位置的垂直參考線、x 軸位置標記或旁註「未來結果尚未觀察」，不得以 0 或舊值代替 y，不將該點放入散點樣本或迴歸。
- 模型預測由分析層提供，使用不同 marker／線型並明示「預測」，不得混充實際點或納入歷史 N。

未知 y 的最小呈現方式（`latest_x` 與 `latest_date_label` 由呼叫端提供）：

```python
ax.axvline(latest_x, color="gray", linestyle=":", label="最新 x；未來結果尚未觀察")
ax.annotate(latest_date_label, xy=(latest_x, 0),
            xycoords=("data", "axes fraction"), xytext=(0, -26),
            textcoords="offset points", ha="center", annotation_clip=False)
```

此處 `0` 是 x 軸的畫布相對位置，不是 y=0 的觀察值；預留底部空間並檢查與刻度／來源不重疊。

## 分組迴歸

當研究假設是「不同狀態下關係可能不同」時，使用 `plot_grouped_regression`，讓各組分別估計截距與斜率。群組必須在估計前定義，不能看完散點後再切出最好看的區間。

- 每個群組至少三筆有效觀測，但樣本過少時即使能畫線，也不宜解讀穩健性。
- 每組使用固定顏色，圖例顯示實際有效分組及樣本數；R² 依媒介選擇，不要把 pooled regression 與分組 regression 的統計量混用。圖例不列不存在的樣本組。
- 圖上的斜率差異是研究線索，不等於已證明結構斷裂；正式判定仍需額外檢定與 out-of-sample 驗證。
- 若群組是 Regime，切分必須使用當時可得的訊號，不可用事後修訂狀態回填。
- 若研究政策環境，依分析層已提供的 regime 上色，不預設按年份。政策月份、模型狀態、進入事件的名稱與來源契約見 [regime-charts.md](regime-charts.md)。
- 1／3／6／12 個月等多 horizon 輸入由分析層算好未來變化及分組；各期各自取有效樣本並標 N，不強制截成最長 horizon 的樣本，除非研究設計明確要求共同樣本。各期期間或 N 不同須揭露。

選用 `assets/financial_charting.py` 的 `plot_regression`、`plot_grouped_regression` 與 `RegressionStats`。既有 OLS 便捷介面保留獨立估計步驟及統計回傳；`show_stats=False` 可精簡文字（分組圖仍留 N）。已有外部估計時可直接 Matplotlib 繪製傳入的擬合線與統計，不為套用 helper 重估模型。helper 不算政策事件、未來變化或分位排名。

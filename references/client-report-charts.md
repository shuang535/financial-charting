# 客戶與研究報告圖表交付

圖表嵌入 Word、客戶／研究報告或小尺寸雙欄版面時使用。通用呈現依 [chart-design.md](chart-design.md)，時間序列／分位數／雙軸依 [time-series.md](time-series.md)，散點與統計依 [regression-charts.md](regression-charts.md)，政策分類依 [regime-charts.md](regime-charts.md)。本文件只補充報告交付要求。

## 最終尺寸與交接

- 呼叫端提供實際目標寬高、媒介及需由文件承接的資訊；不硬編碼固定 Word 欄寬或英吋數。缺少尺寸時先確認，或明確標為尚未完成最終尺寸驗收。
- 依目標尺寸反推字級、圖例、來源換行及繪圖區；雙欄或一頁兩圖需要小圖時，輸出適配版本，不單純將大圖等比縮小。只交付有要求的版本。
- 以最終物理尺寸檢查標題、刻度、軸名、圖例、最新值、統計與來源；長文字不得把主繪圖區壓得難以解讀。不能以提高 DPI 取代字級與版面調整。
- 本 skill 負責圖片在指定顯示尺寸的檢查。呼叫端保留輸出尺寸及預期插入尺寸；`macro-research-report` 負責插入 Word 後渲染實際頁面，核對是否再次縮放、裁切或重疊。圖片檢查通過不等於 Word 落版驗收通過。

## 圖片自足性與文件資訊歸屬

預設圖片能獨立閱讀，包含完整標題（呼叫端需要時含圖號）、左右軸名稱／單位、必要圖例、與研究問題相關的最新值或重要統計、樣本期間／截止日與實際來源。

- 日期按用途標為 `資料截至 YYYY/MM`、`樣本期間 YYYY/MM–YYYY/MM` 或 `共同樣本 YYYY/MM–YYYY/MM`；日頻或事件研究保留必要的日精度。各序列截止日及估計樣本不同時不可用一個日期含糊代替。
- 文件模板若明確承接圖號、標題、來源或日期，可輸出精簡嵌入版，並將移出的資訊隨圖交付；不得默默遺失。單位、序列辨識及影響判讀的註記仍留圖內。
- 主題／標題、來源、截止日已在圖內時，交接要求文件外層不重複同一組資訊。圖中已有最新值，也不需在圖說重述。
- 草稿 A／B 是版本識別，不是正式圖號；定稿圖號由報告依最終排序提供，輸出時不把版本字母留在正式圖號。

## 客戶用語與揭露

名稱與資料識別碼分開保存，沿用 [chart-design.md](chart-design.md) 的口徑要求。客戶圖不直接顯示未解釋 ticker、Python 欄位、資料庫／資料夾名、內部模型縮寫或 `G|T` 等情境代碼；由呼叫端提供可理解的顯示名稱，例如「景氣成長」「政策緊縮」，但不可改變實際分類定義。

涉及內部模型時只呈現本次授權的環境判定、指標方向與歷史結果；不因要交代 regime 定義而揭露模型成分、權重、分數或門檻。內部研究圖亦依已確認的揭露範圍，不因媒介不同自動擴權。

## 選用國泰設定

僅在交付情境明確需要時啟用，不改變所有用途的預設。來源可用：

`Source: {實際資料提供者}，國泰投信整理`

呼叫端須明確指定提供者及整理機構；不以 MyDB、SQL 或檔名替代提供者。`assets/cathaysite.mplstyle` 可提供品牌字型、基礎色循環及 300 DPI；語意色由呼叫端 mapping 指定，不能靠循環色猜政策意義。

| 用途 | 建議顏色 |
|---|---|
| 主要序列 | 深藍 `#002060` |
| 次要序列 | 淺藍 `#18C1FF` |
| 明確指定的升息／緊縮／警示 | 紅 `#C83E4D` |
| 明確指定的降息／寬鬆 | 淺綠 `#83BC5C` |
| 比較柱／其他歷史樣本 | 淺灰 `#BFBFBF` |
| 零線／基準線／長期平均 | 深灰 `#343A40` |

此表為選用建議，主次序列不強制綁定左右軸。不同語意容易混淆時搭配線型、marker 或直接標籤；政策紅綠不自動套到所有資產漲跌。已有專案設計系統時優先沿用。

## 資訊密度與分工

研究版可展示完整統計，客戶小尺寸版依 [regression-charts.md](regression-charts.md) 精簡；未畫出的統計留在研究紀錄，不為小圖刪除估計證據。最新值、分位排名、r 或 R² 是否需要，以研究判斷及版面為準。

圖表呈現方向、相對位置、最新狀態、歷史分布與統計關係；不塞入整段投資評論。`macro-research-report` 負責研究方法、重要性、傳導機制、報告故事線、投資含意、正文及文件組版，也負責避免正文逐項重述圖中數字。本 skill 不固定頁數、圖數、字數、章節、當期數字或投資結論。

交付時附上版本／正式圖號對照、實際圖片尺寸、預期插入尺寸、資訊由圖內或文件承接的約定，以及圖片檢查結果；這些是按需交接資訊，不要求額外建立固定格式的檔案。
